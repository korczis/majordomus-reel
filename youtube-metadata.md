## Video 2: majordomus-reel-v3.mp4 (112 s, the long cut)

**Title** (79/100)

AI coding agents, supervised: one policy, one board, proof of done | Majordomus

**Description**

Your AI coding agents say the work is done. Majordomus makes them prove it.

Majordomus is an open-source supervisory layer for AI coding agents: Claude Code, Codex,
Gemini CLI, or any other.

- Three commands to start: install, majordomus init, majordomus start with a scope
- Each agent reads only the rules along the path it works on
- majordomus finish checks blockers, scope, state and tests, and refuses until they pass
- Claude, Codex and Gemini share one board; overlapping edits are reported before the merge
- One stream follows every session, claim, review and merge, on every machine
- One policy writes CLAUDE.md, AGENTS.md and GEMINI.md
- Tasks and handovers live in git, so tomorrow's agent continues where tonight's stopped
- Runs locally and never calls a model

Three theses close it: done is a contract, not a feeling; agents prove, they do not promise;
the repository remembers what the chat forgets. Agents were a leap forward. Trust is the next one.

Website: https://majordomus.dev
Watch it refuse an agent: https://majordomus.dev/challenge/
Source (MIT): https://github.com/korczis/prismatic-majordomus
Install: curl -fsSL https://majordomus.dev/install.sh | sh

The numbers in the video (0-9 % shared rules, 17 checks invoked by nothing, about 3,200 files
modified at once across forty worktrees) were measured in the repositories Majordomus was
distilled from; the README tells the full story.

Music and sound design were synthesised for this video; narration is a synthetic voice.
